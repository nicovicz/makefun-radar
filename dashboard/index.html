METHODOLOGY / READ BEFORE USING

A comparable
starting point.

Implied value is a scenario based on recorded TVL, not a token price, fully diluted valuation, or a forecast of a launch. The snapshot cannot establish whether a token or rewards program actually exists.

01 / CATEGORY (SHRUNK)

Clamped peer market cap ÷ TVL (0.05×–12×) shrunk toward the global snapshot median with a 3-peer Bayesian prior so thin 1-peer categories never distort ranks.

02 / MOMENTUM

1 + clamped 7-day TVL change ÷ 200, with change limited to −50%…+50%. Missing change uses 0%.

03 / MATURITY

0.75 + 0.25 × min(days since listing, 730) ÷ 730. Missing dates use 365 days. Listing age is only a proxy for operating history.

04 / BREADTH

1 + 0.05 × min(max(chain count − 1, 0), 4). Multiply all four terms by TVL and round to whole dollars.

CONFIDENCE / INPUT COVERAGE

Higher: at least 3 priced peers, reported growth, age and a chain. Medium: at least one peer, reported growth and age. Limited: otherwise. This describes data completeness, not statistical certainty. Peer ratios can be distorted by outliers and token supply.
